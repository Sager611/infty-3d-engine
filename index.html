ControlsClick an object to inspect it. Alt-click or use Pick all for every ray intersection on the next click. Drag to orbit, scroll to zoom, arrows orbit, +/− zoom, R resets.

SceneSphere and infinite-plane intersections are exact analytic hits. Quartic surfaces use analytic polynomial refinement, not ray marching: their gaps are bounded estimates with uncertainty. An infinite plane has no finite silhouette.

MetricsCPU submission walltime is JavaScript wall-clock around render submission, not CPU percent or GPU time. JS/WASM are memory readings, not GPU memory.

DetailExisting nested coordinate-hashed UV tiles use three adjacent powers-of-two grids, smoothly blended from estimated pixel footprint ρ. No loops or bitmap; finite float and pixel precision limits remain.
